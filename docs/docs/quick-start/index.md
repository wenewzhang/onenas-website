# 5分钟快速安装 OneNAS

本指南将帮助您在 5 分钟内完成 OneNAS 的基础安装和配置。

## 准备工作

在开始之前，请确保您已准备好以下物品：

- [ ] OneNAS 设备或一台兼容的计算机
- [ ] 至少一块硬盘（推荐使用 SSD 作为系统盘）
- [ ] 网线一根
- [ ] 可正常工作的网络环境

## 安装步骤

### 1. 连接硬件

1. 将硬盘安装到设备中
2. 连接网线到路由器/交换机
3. 接通电源并开机

### 2. 获取 IP 地址

设备启动后，会自动从路由器获取 IP 地址。您可以通过以下方式查看：

- 登录路由器管理界面查看设备列表
- 使用 `OneNAS.local` 域名访问（需支持 mDNS）

### 3. 初始化配置

在浏览器中访问获取到的 IP 地址，您将看到初始设置向导：

1. **设置管理员密码**
   - 输入并确认您的管理员密码
   - 密码长度至少 8 位，建议包含字母和数字

2. **配置网络**
   - 选择是否使用 DHCP 自动获取 IP
   - 或手动设置静态 IP 地址

3. **创建存储池**
   - 选择要使用的硬盘
   - 选择 RAID 类型（推荐 RAID 1 或 RAID 5）

4. **完成设置**
   - 确认配置信息
   - 点击"完成"按钮

## 验证安装

安装完成后，您可以：

1. 登录 Web 管理界面
2. 创建一个测试共享文件夹
3. 从电脑访问 `\\OneNAS.local\共享文件夹名`

## 常见问题

### 无法访问 Web 界面？

- 检查网线是否连接正常
- 确认设备指示灯状态
- 尝试使用 IP 地址直接访问

### 硬盘未被识别？

- 确认硬盘已正确安装
- 检查硬盘是否兼容
- 尝试重新插拔硬盘
