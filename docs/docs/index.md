# OneNAS 官方文档

欢迎来到 OneNAS 官方文档中心！

OneNAS 是一款高性能、易用的网络附加存储（NAS）解决方案，专为家庭和小型办公室设计。

## 快速开始

如果您是第一次使用 OneNAS，建议从 [5分钟快速安装](quick-start/index.md) 开始。

## 主要特性

- 🚀 **高性能**: 基于现代存储技术，提供极致的读写性能
- 🔒 **安全可靠**: 支持多种 RAID 配置和数据保护机制
- 🌐 **易于访问**: 支持 SMB协议, Windows的好伙伴
- 📱 **随时随地**: 通过 Web 界面和移动应用远程管理
- 🛠️ **简单维护**: 直观的图形界面，轻松完成日常维护
