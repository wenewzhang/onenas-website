## OneNAS Introduction

OneNAS is an open-source network-attached storage (NAS) system built on Debian 13. It uses OpenZFS 2.4.2 as the core file system and integrates ZFSbootmenu for flexible boot management.

### Key Features

- **Modern File System**: Powered by OpenZFS 2.4.2, supporting enterprise-grade data protection features such as snapshots, checksums, compression, and deduplication.
- **Rich RAID Support**: Supports multiple RAID configurations including RAID0, RAID1, RAID10, RAIDZ1, RAIDZ2, and RAIDZ3 to meet diverse storage needs.
- **ZFSbootmenu**: Integrates ZFSbootmenu for more flexible and reliable system boot and recovery.
- **Samba File Sharing**: Native support for the Samba protocol, enabling seamless file sharing with Windows, macOS, and Linux clients.
- **Simple Permission Management**: Provides an intuitive and straightforward permission control mechanism, allowing users to manage users and shared folders without deep expertise.
