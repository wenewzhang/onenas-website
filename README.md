## OneNAS 介绍

OneNAS 是一款基于 Debian 13 开发的开源网络存储系统，采用 OpenZFS 2.4.2 作为核心文件系统，并集成 ZFSbootmenu 实现灵活的启动管理。

### 主要特性

- **现代文件系统**：基于 OpenZFS 2.4.2，支持快照、校验和、压缩、去重等企业级数据保护功能。
- **丰富的 RAID 支持**：支持 RAID0、RAID1、RAID10、RAIDZ1、RAIDZ2、RAIDZ3 等多种 RAID 配置，满足不同场景的存储需求。
- **ZFSbootmenu**：集成 ZFSbootmenu，提供更灵活、可靠的系统启动与恢复能力。
- **Samba 文件共享**：原生支持 Samba 协议，可无缝与 Windows、macOS 及 Linux 客户端共享文件。
- **简单权限管理**：提供简洁直观的权限控制机制，无需复杂的专业知识即可轻松管理用户与共享目录。
